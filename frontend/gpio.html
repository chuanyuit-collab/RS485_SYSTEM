📡 MQTT 遠端整合說明

本系統已內建 MQTT 控制功能（需先至「系統設定」開啟 MQTT 並設定伺服器）。
您可以透過以下 Topic 格式，將此設備的 GPIO 整合至 Home Assistant、Node-RED 或其他中控系統：

讀取 GPIO 狀態 (Subscribe)

  • Topic: rs485_sys/gpio/status
    或 [MAC位址]/STATUS
  • Payload: JSON 格式字串
  • 說明: 當狀態改變或每 5 秒會自動發布包含所有 Inputs 與 Outputs 狀態的 JSON。

控制 GPIO 開關 (Publish)

  • Topic: rs485_sys/gpio/set/<腳位>
    或 [MAC位址]/CTRL/<腳位>
  • 範例: rs485_sys/gpio/set/26
  • Payload: 1 或 0 (也支援 on/off)
